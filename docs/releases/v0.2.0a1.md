# GUI research preview

This prerelease provides a local browser interface and lightweight Python workflow package.
It is **not independently end-to-end or clinically validated**. It must not guide patient treatment.

## Added

- CT shaft candidate + constrained connected MRI-void extraction, with separate metal/void/mask outputs.
- RAS image editor for shaft points, MRI-only manual seeds, virtual exclusion geometry and audited local mask corrections.
- Immutable corrected-mask adoption with fresh downstream QC approval.
- QC-gated ACT/exclusion audit/SIFT2/connectome handoff and interactive G1–G4/matrix reports.
- Explicit training-mean references and paired same-reference gradient/eccentricity change reports and CSV.
- Optional external OSS-DBS single-lead, voltage/current, isotropic single-frequency field model with
  thresholded VTA-like NIfTI and local slice viewer. No axon activation or pulse-width model.

## Verification and limitations

113 local synthetic tests passed. Installed MRtrix downstream processing and OSS-DBS 0.5.9 voltage/current
phantom FEM were exercised, as were browser candidate generation, handoff, manual correction, FEM and
paired-gradient controls. The wheel contains only application code/assets, not external MRI/FEM tools.

No patient data are included. Original images are read-only; outputs require a separate directory.
The CT/MRI candidate algorithm is not a proven reproduction of the paper's original void-follow mask.
MRI-only automatic localization, physical contact/tip/rotation reconstruction, longitudinal mask
registration, LOSO automation, FEM convergence and complete independent patient validation remain open.

Install the wheel into a dedicated Python environment, or install from the tagged source.
