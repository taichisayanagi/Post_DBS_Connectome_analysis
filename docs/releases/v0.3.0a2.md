# v0.3.0a2 — extended supplementary replay

Research preview, **not** full-image-to-paper certification or clinical validation.

Adds GUI/CLI operations for cross-cohort replication/reference transfer, mask-calibre
ICC, five lateralized definitions, symptom-dominant-side analyses, and the historical
280/322/420-test inventories. All supplied outcomes and unfavourable findings are retained.

New real-data numerical checks: 260 comparative values, 54,516 lateralized/symptom-side
values and 9,814 inventory values matched independently frozen outputs. 164 local tests
passed. Patient data and private fixtures are not included in this distribution.

Provenance findings are explicit: legacy matched replication used ten computed axes;
four-axis results are separate. The old exploratory variance ratio is not an ICC.
Shared and session mask inputs are not interchanged. These software checks do not
resolve manuscript interpretation or the older quarantined surface-graph lineage.

Real anatomical reconstruction is still being validated. Expert mask/atlas review,
full new-image ACT/SIFT2 execution and every adopted figure are not yet certified.
