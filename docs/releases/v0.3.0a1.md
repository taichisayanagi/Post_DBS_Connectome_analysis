# v0.3.0a1 — numerical replay research preview

This prerelease extends the existing GUI imaging workflow with a hash-bound numerical
replay suite. **It is not a fully validated DICOM-to-paper pipeline or a clinical tool.**

## Added

- Cohort common/LOSO gradients, hemisphere-aware measures, exact clinical tests,
  multiplicity accounting and interactive heatmap/Theil–Sen reports.
- Fixed-cost graph/node/edge summaries and a separately declared unmasked preoperative basis.
- Eight-setting sensitivity, unmasked/healthy reference validation, same-day and synthetic-void
  controls, geometry/distance/Mantel tests, and matched-map representation comparisons.
- Original study void-follow candidates, immutable historical mask corrections and paired
  native-grid shared-mask preparation. New image QC remains mandatory.
- Per-task passed/failed/unverified status, immutable input hashes and source-package hashes.
- macOS NextBrain child-process atlas-loader compatibility; installed tools are never patched.
- Synthetic cohort example and 151 passing local regression/unit/integration checks.

## Scope and known limitations

Historical primary numerical arrays and several supplemental controls were independently
recomputed. Real-image anatomy/full-chain validation and remaining supplementary families
are incomplete. A historical surface-graph source discrepancy is explicitly retained as an
open gate. Patient data, images, clinical tables and private expected outputs are not shipped.

Read `docs/PAPER_REPLAY.md` and `docs/VALIDATION_REPLAY_20261024.md` before interpreting
"verified numeric replay". External FSL/MRtrix3/FreeSurfer/NextBrain/OSS-DBS installations
and atlas/model licenses remain the user's responsibility. This is a lightweight wrapper,
not an all-in-one neuroimaging distribution.
