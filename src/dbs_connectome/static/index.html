4. Atlas and electrode mask

Reconstruction output is linked automatically. Configure trusted installed resources once. FreeSurfer and NextBrain run locally; model files are not bundled. A frozen node TSV defines source labels and cohort-wide node correspondence.

The editor combines CT shaft candidates with a constrained MRI void, or accepts manual / virtual centerlines. Correct the candidate on images, then inspect its voxel mask. It never automatically approves QC.

5. Review and continue to gradients

After preparation, the exact atlas, 5TT, mask, FOD and node table are handed to tractography without manually rebuilding file lists. Check the images before approval. Ambiguous CT candidates or missing nodes stop processing.

The default is one million. A reduced count is for smoke testing only. Without a training or independent gradient reference, outputs are single-session unaligned G1–G4 and cannot be used directly for longitudinal comparison.

Select NIfTI files or a DICOM folder to begin.

6. Optional electric field / VTA-like simulation

Separate OSS-DBS finite-element solver. Single-lead, single-frequency, isotropic quasi-static model with a grounded spherical outer boundary. This is NOT the electrode artifact mask, a pulse-width-dependent axon activation model, or a programming recommendation.

Required labels: 0 unknown, 1 CSF, 2 white matter, 3 gray matter, 4 blood. Raw T1/T2, atlas labels and exclusion masks are not acceptable tissue maps. Inspect the candidate separately before use. Set OSSDBS_PYTHON to the solver environment before starting this application.

No simulation run.
